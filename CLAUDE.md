# Project instructions

- For UI work, follow the style principles in `uploads/DESIGN-notion.md`: warm off-white page background (#f6f5f4), white cards, near-black Inter type with tight negative tracking on headlines, one accent colour for actions and links only, 1px hairline borders (#e6e6e6), very soft layered shadows, 12px card corners, pill-shaped main buttons, 8px utility buttons, 4px form inputs, and lots of whitespace.
- Adapt these principles into an original look. Don't copy Notion's own signature elements (the sticker illustrations, the indigo "night" hero, the Notion wordmark or UI).
